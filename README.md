# Odyssey Lands

A Minecraft community built around exploration, thoughtful builds, and stories that grow with the world.

## Visit the world

- **Website:** https://alonemanguy.github.io/odyssey-lands-site/
- **Discord:** https://discord.gg/fvbDtwzPWP
- **Minecraft address:** `OdysseyLand.aternos.me:46767`

## What Odyssey Lands is about

Odyssey Lands is an ocean-themed community where players can build, explore, take part in expeditions, and help shape a shared world. The project is organised around six districts and a five-rank journey from Drifter to Warden.

The website is a small public home for the community: it introduces the world, explains the different ways to join in, and points new crew toward Discord.

## Project notes

This repository contains the public landing page for Odyssey Lands. It is a single responsive page with a small interactive voyager-path selector and no external framework or tracking code.

The site is published with GitHub Pages from the `main` branch.
